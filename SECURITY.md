# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository. Include the affected
commit or release, the component, the impact and a minimal reproduction.

Do not include private keys, mnemonics, one-time passwords or wallet session
data in a report. Do not test against third-party systems or other users'
assets.

We will acknowledge a report as soon as possible and keep you informed while a
fix is prepared.
